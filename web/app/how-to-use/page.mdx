# 使用說明

Mito 是個羽球跑位訓練工具：在「跑位管理」建立 3x3 跑位動作序列，在播放頁面播放設定好的動作序列，
同時也可以一鍵遠端控制其他裝置同步顯示。首頁就是「裝置頁」，會顯示這台裝置的名稱
（例如 `喜歡-貓咪-哥本哈根`），並等待被教練端遠端控制。

## 建立與編輯跑位

點右上角的齒輪按鈕進入跑位管理，按「新增跑位」建立跑位。在編輯頁：

- 點 3x3 格子設定該動作的位置
- 用 − / ＋ 或直接輸入數字調整秒數
- 拖曳左側把手調整動作順序
- 點鉛筆修改名稱與描述，變更會自動儲存

## 刪除跑位

在跑位列表把游標移到項目上，點垃圾桶圖示並確認即可刪除。

<video controls preload="metadata" className="w-full rounded-xl border not-prose" src="/demo_video/how_to_delete_a_workout.mov"/>

## 播放跑位

在編輯頁按綠色播放鍵進入播放器，選擇播放模式（單次／重複次數／無限循環）後開始。
播放中可以隨時暫停、繼續或停止。

<video controls preload="metadata" className="w-full rounded-xl border not-prose" src="/demo_video/how_to_use_player.mov"/>

## 遠端控制其他裝置

其他裝置停在首頁（裝置頁）時，播放器的「遠端控制」按鈕會列出所有連線中的裝置。
勾選要控制的裝置並按「連線」，它們會立刻進入播放畫面並顯示「遠端控制中」標籤；
之後的開始／暫停／停止都會同步。按「中斷連線」或離開播放器，被控裝置就會自動回到首頁結束被教練端的控制。
